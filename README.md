# Gett - Travel Itinerary & Recommendation System

## 🌍 Project Overview
**Gett** is a full-stack travel application designed to help users discover places and generate personalized travel itineraries. By leveraging a recommendation engine, the system suggests destinations based on user preferences and reviews, allowing travelers to plan their trips efficiently.

## 🚀 Features
- **Smart Recommendations:** Suggests places to visit based on user ratings and database records.
- **Itinerary Management:** Users can view and organize their travel plans.
- **Place Search:** functionality to explore various travel destinations.
- **Review System:** Integration for fetching and displaying place reviews.
- **Modern UI:** A responsive frontend built with React and styled for a seamless user experience.

## 🛠️ Technology Stack

### Backend
- **Python** (3.x)
- **FastAPI:** High-performance web framework for the API.
- **MongoDB:** NoSQL database for storing places, itineraries, and reviews.
- **Motor/PyMongo:** Asynchronous MongoDB driver.

### Frontend
- **React.js:** Component-based UI library.
- **Vite:** Next-generation frontend tooling for fast builds.
- **React Router:** For dynamic client-side routing.
- **CSS Modules:** for styling.
